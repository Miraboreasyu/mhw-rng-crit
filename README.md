# `rng_crit` —— 攻击会心率与分配模式控制插件

- **插件标识**：`crit`（编译产物 `rng_crit.dll`，版本 `1.0.0`）
- **源码位置**：[crit_plugin.cpp](crit_plugin.cpp)
- **宿主依赖**：`mhw_rng.dll`（Plugin SDK `kMhwRngApiVersion == 3`，头文件 [mhw_rng_api.h](include/mhw_rng_api.h)）
- **接入点位**：
  - MIRA 内核 RNG 槽位：`RVA 0x01F606D6`（`pl.crit_seed`，动作起手抽样与 `Epoch`/`Seed`/快照联动）
  - 插件内自包含热重载钩子：`RVA 0x01F51380`（`FUN_141f51380`，仅拦截本地主玩家，远程队友 100% 原版放行）

`rng_crit` 支持无视配装面板自由覆写目标会心率（`-100% .. +100%`）或自动跟随游戏实时会心率（含看破、弱点特效与软化），并提供纯随机无保底、严格按有效命中的 `m:n` 比例/自定义序列、高动作值优先预算池 `mv_bank`、动作值分档独立流 `mv_tier`、洗牌袋 `bag` 与 `prd` 渐进保底等多种会心分配模式。

## 一、15.23 逆向机制与精确挂钩点

对《怪物猎人：世界 冰原》Steam 15.23（镜像基址 `0x140000000`）攻击暴击与动作值管线的分析表明，游戏采用“动作起手一次性抽种子 + 命中逐跳位移消耗 + 实时计算面板会心”的两阶段结构：

1. **阶段一：动作起手 RNG 抽样（`0x141f605f0` / `RVA 0x01F606D6`）**
   - 本地主玩家（`[uPlayer + 0x8938] & 1` 为真）在动作起手时调用 `MtRandom::nrand(&sInstance)`，截取低 27 位种子 `S = raw & 0x07FFFFFF` 写入 `[uPlayer + 0x8818]`，将 32 位移位工作种子 `seed32 = (S << 27) | S` 写入 `[uPlayer + 0x881C]`，并清零命中游标 `[uPlayer + 0x8820] = 0`。
   - 联机发包（`0x14119c27c..29c`）仅打包 `([uPlayer + 0xAB18] << 27) | S`（高 5 位异常游标 + 低 27 位会心种子）发送；接收端经 `0x1411b4a10 -> 0x141f73a10` 解包并拼接出完全一致的 `seed32`，从而使同招多段攻击各客户端表现一致。
2. **阶段二：命中实时会心判定与倍率计算（`0x141f51380`）**
   - 命中瞬间不再调用 `nrand`，而是将 `[uPlayer + 0x881C]` 按 `[uPlayer + 0x8820]` 逐位循环旋转并与通过 `0x1411c1f50` + `0x1411b9950` 实时求出的面板+弱特+软化会心率比对，将结果 `+1`（正会心）/ `0`（普通）/ `-1`（负会心）写入 `atkParam + 0x160`。
   - 随后按判定结果调用原生超会心倍率表 `0x1411c0940`（`1.25x..1.40x`）或负会心倍率 `0x1411c0620`（`0.75x`）缩放物理伤害。
3. **未缩放原始动作值（MV）读取与联机队友隔离**
   - `FUN_141f66dd0` 在调用 `0x141f51380` 前，会先把可变参数副本 `atkParam + 0x20`（即 `HitInfo + 0xB8`）覆写为包含真蓄倍率、面板攻击力与斩味的会心前基础伤害。
   - `rng_crit` 从不可变动作节点链 `(*critCtx->hitInfoPtr)->cNode(+0x38)->origAtkParam(+0xA8)->+0x20`（并处理双刀/铳枪等武器类型 `3` / `9` 的 `+0x264` 派生动作值）读取真实物理动作值（MV），仅在写入最终会心倍率时乘回可变 `atkParam + 0x20`；同时对 `[uPlayer + 0x8938] & 1 == 0` 的远程联机玩家实体 100% 原版放行。

## 二、核心功能与分配模式

1. **会心率来源（`rate`）**
   - `auto`（默认）：每跳实时调用游戏原生 `0x1411c1f50` + `0x1411b9950`（自动包含弱点特效、软化部位、挑战者、拔刀术【技】等一切即时修正）。
   - `<-100..100>`：强制设定固定目标会心率（即使武器原面板为 `0%`、`-30%` 或 `100%` 均可精准生效）。切换至 `random` / `mv_bank` / `mv_tier`（`delta=`）/ `bag` / `prd` 时若仍开启着手动覆写，会自动提醒可用 `$rng crit rate auto` 恢复跟随实时面板。
2. **`random`（纯随机无保底，内核 `CondID 1`）**
   - 破除原版多段招式共用 32 位种子逐位右移的伪相关性，每次真实命中由 MIRA 独立确定性随机流采样，支持 `$rng seed` / `$rng reset` 复现。
3. **`ratio <m:n> [block|spread]` 与 `seq <pattern>`（严格命中定比/自定义序列）**
   - 仅按真正击中目标的跳数推进（翻滚、垫步、空挥绝不消耗次数）。
   - `block` 为连续块状（先 `m` 次会心再 `n` 次不会心）；`spread` 为 Bresenham 均匀交错；`seq` 支持循环序列（如 `11010`、`++-0`）。每跳详细播报会显示当前步数/定比进度（如 `[序列 3/6]` / `[定比 3:2 步2/5]`）。
4. **`mv_bank [threshold=50] [reserve=1.0]`（高动作值优先预算池）**
   - 每次命中向预算池充入 `|aff| / 100` 暴击额度；低动作值小招（`< threshold`）默认把额度攒下，仅当当前额度达到小招溢出线 `1.0 + reserve`（默认 `2.00`）时才消耗 `1.0` 溢出暴击，从而至少为大招保留 `reserve` 额度；而高动作值大招（`>= threshold`，如大剑真蓄力斩第二刀 `264`、蓄力斧解等）只要池满 `0.5` 即优先消耗 `1.0` 额度必暴。
   - 长期总会心次数严格收敛至设定/实时会心率，低 MV 武器也不会被饿死。
5. **`mv_tier [c1 c2 ...] [delta=d1,d2,... | rate=r1,r2,...]`（动作值分档独立流）**
   - 根据真实物理动作值路由至彼此独立的内核 `CondID 10..17`（支持 1~7 个递增分界点，自动划分 `N+1` 档；不带分界时默认 `25 60`，各档默认均 `+0%` 偏移）。
   - 可选 `delta=...` 叠加相对会心偏移，或 `rate=...` 直接指定各档绝对会心率（均严格校验 `-100..100` 与档位数量一致，绝不静默截断）。
6. **`bag [size=10]` 与 `prd`（洗牌袋与渐进保底）**
   - `bag` 使用带小数余数进位的确定性 Fisher-Yates 洗牌袋，并按实时会心率自动分桶缓存（打弱点/非弱点来回切换不串袋）；
   - `prd` 精确二分求解期望一致的渐进概率常数 $C(p)$，在严格维持期望会心率的同时封顶最大连黑次数。

## 三、聊天/终端指令表

| 指令 | 说明 |
| :--- | :--- |
| `$rng crit` / `$rng crit status` | 查看当前模式、会心率来源、详细播报状态、总命中/正负会心/MV 加权会心率统计 |
| `$rng crit rate <auto\|-100..100>` | 切换实时游戏会心率 (`auto`) 或手动覆写固定百分比 |
| `$rng crit random` | 切换为纯随机无保底 (`CondID 1`) |
| `$rng crit ratio <m:n> [block\|spread]` | 按真命中循环执行 `m` 次会心 / `n` 次不会心 |
| `$rng crit seq <10+-.>` | 自定义循环序列（`1`/`+` 正会心、`0`/`.` 普通、`-` 负会心） |
| `$rng crit mv_bank [mvTh] [reserve]` | 高动作值优先预算池（默认阈值 `50.0`，大招预留 `1.0`，小招溢出线 `2.0`） |
| `$rng crit mv_tier [c1 c2 ..] [delta=\|rate=]` | 按动作值分档路由到独立 `CondID 10..17`（1~7 个分界，默认各档 `0%` 偏移） |
| `$rng crit bag [N]` / `$rng crit prd` | 确定性洗牌袋（默认容量 `10`）或 PRD 渐进保底 |
| `$rng crit observe` / `$rng crit off` | 原版判定仅观测统计 / 彻底还原原版逻辑 |
| `$rng crit verbose [on\|off]` | 开关每跳命中详细异步播报（默认关闭） |
| `$rng crit reset` / `$rng crit help` | 重置命中统计与内部游标/预算池 / 查看帮助 |

> [!NOTE]
> 所有已施加的正会心/负会心结果均写回标准 `cAttackParam+0x160` 与物理伤害 `+0x20`，并与原版超会心（`1.25~1.40x`）、属性会心/真属会、特殊会心及红/蓝暴击特效 100% 原生联动。

## 四、独立构建与热重载

```bat
:: 1. 从核心仓库同步 include\mhw_rng_api.h（不传参默认查找 ..\..\include 或 %MHW_RNG_SDK_DIR%）
sync_sdk.bat <path-to-mhw-rng>

:: 2. 编译生成 build\rng_crit.dll（或带 --deploy 部署到游戏目录）
build.bat --deploy
```

部署后若游戏正在运行，在游戏内终端或聊天框输入 `$rng reload crit`（首次安装输入 `$rng load crit`）即可热重载生效。
